# The Ordinary Ward — GitHub Pages edition

This folder contains the self-contained public editions of **The Ordinary Ward · Releases 2 and 3**.

- `index.html` — the complete four-unit teaching suite.
- `ward.html` — detachable Unit 4 for a roster-focused audience.
- `designated-nurse-analysis.html` — generate a responsive rank-frequency profile from the ward’s active settings and compare it with an unloaded D profile in the same ward-acuity environment.
- `ward-release-3.html` — the Release 3 responsibility-loading explorer. Release 2 remains available at `ward.html`.
- `designated-nurse-analysis-r3.html` — the Release 3 paired on-duty overlap analysis opened from the Release 3 explorer.
- `designated-nurse-loading.html` — the earlier loading comparison retained so existing links continue to work.
- `release-1/index.html` — the preserved Release 1 shift-level explorer.

## Publish it

1. Create a new GitHub repository.
2. Upload `index.html`, `ward.html`, `designated-nurse-analysis.html`, `ward-release-3.html`, `designated-nurse-analysis-r3.html`, `analysis-worker.js`, `ward-worker.js`, and the `release-1` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select the root of the main branch.
4. Open the GitHub Pages URL GitHub supplies.

No build command, package installation, server, API key, sign-in or sign-up is required. Every simulator runs entirely in the visitor's browser.

The complete suite opens at the repository's GitHub Pages address. Release 2 opens at `/ward.html`; Release 3 opens at `/ward-release-3.html` and launches its paired analysis at `/designated-nurse-analysis-r3.html`; Release 1 remains available at `/release-1/`.

The source links inside lessons 02 and 03 are the only outbound network links. Each HTML file contains its own design, teaching content and simulation code.
