# The Ordinary Ward — GitHub Pages edition

This folder is the complete, self-contained public edition of **The Ordinary Ward**.

## Publish it

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select the root of the main branch.
4. Open the GitHub Pages URL GitHub supplies.

No build command, package installation, server, API key, sign-in or sign-up is required. The three probability lessons and the ward simulator all run in the visitor's browser.

The source links inside lessons 02 and 03 are the only outbound network links. All design, teaching content and simulation code are contained in `index.html`.
